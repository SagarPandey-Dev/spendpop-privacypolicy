# SpendPop - Privacy Policy

This repository hosts the official, public Privacy Policy for **SpendPop: Expense & Budget** (`in.nbound.spendpop`), developed by **NBOUND** (*"Beyond The Boundaries"*).

## Live Privacy Policy URL
The policy is published via GitHub Pages:
🔗 **[https://sagarpandey-dev.github.io/spendpop-privacypolicy/](https://sagarpandey-dev.github.io/spendpop-privacypolicy/)**

## Summary
- **Zero Cloud Tracking:** All expense and budget data stays 100% locally on the user's device in an encrypted/sandboxed SQLite database.
- **No Sign-Up Required:** No registration, email, or account needed.
- **Transparent Permissions:** `SYSTEM_ALERT_WINDOW` is used strictly for the optional quick-capture floating button and never reads screen or clipboard data.
- **Google Play Store Compliant:** Meets all Google Play User Data policies, sensitive permission justifications, and advertising disclosure guidelines.
